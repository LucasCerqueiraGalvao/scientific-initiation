# Reuniões

Registros das reuniões da iniciação científica. Cada reunião fica em uma pasta
identificada pela data e separa o material bruto da interpretação usada no
andamento do projeto.

## Convenção

- `transcricao-completa.md`: cópia integral bruta do registro de origem;
- `transcricao-completa.tex`: versão LaTeX compilável da transcrição;
- `registro.tex`: síntese, decisões, situação e próximos passos;
- `README.md`: índice curto para navegação no GitHub.
